📚 Supported Threat Modeling Methodologies & Standards

STRIDE Methodology

Technical Threat Analysis

Originally developed at Microsoft, STRIDE categorizes threats into Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service, and Elevation of Privilege. It provides an exhaustive decomposition of software and embedded system data flows.

Spoofing (Identity) Tampering (Integrity) Repudiation (Non-repudiation) Info Disclosure (Confidentiality) Denial of Service (Availability) Elevation of Privilege (Authorization)

PASTA (Process for Attack Simulation and Threat Analysis)

Risk-Centric Framework

PASTA is a risk-centric threat modeling methodology consisting of seven stages. It aligns technical security vulnerabilities with business objectives, financial impact, and threat intelligence regarding real-world adversaries.

Stage I: Define Objectives Stage II: Technical Scope Stage III: Application Decomposition Stage IV: Threat Analysis Stage V: Vulnerabilities Stage VI: Attack Modeling Stage VII: Risk & Impact

MAESTRO Framework for Agentic AI

AI & Multi-Agent Systems

Designed specifically for generative and autonomous multi-agent AI pipelines. Evaluates prompt injection, autonomous goal hijacking, tool abuse, RAG vector poisoning, and multi-agent swarm coordination subversion.

Layer 1: Foundation Models Layer 2: Autonomous Agents Layer 3: Tools & Integrations Layer 4: Memory & Vector Stores Layer 5: Inter-Agent Transport Layer 6: Multi-Agent Swarms Layer 7: UI & Human Gates

ISO/SAE 21434 TARA (Automotive Cybersecurity)

Automotive Engineering Standard

The international road vehicles cybersecurity engineering standard. Assesses vehicle Item definitions, damage scenarios across SFOP (Safety, Financial, Operational, Privacy), attack feasibility ratings (time, expertise, knowledge, window, equipment), and formal Cybersecurity Goals.

Item Boundary Damage Scenarios (SFOP) Attack Paths Feasibility Rating Risk Matrix (1-5) Cybersecurity Goals (CG)

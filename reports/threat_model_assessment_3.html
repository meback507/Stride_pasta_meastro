Layer 1: Model & Foundation LLM

Adversarial Jailbreak & System Prompt Extraction on Telematics Unit

Target: Telematics Unit • Asset: Braking Signal • Status: APPROVED
Critical (20/25)

Adversarial formatting (base64 obfuscation, multi-turn roleplay, or token manipulation) bypasses system guardrails to extract underlying system instructions and confidential proprietary rules.

Attack Vector: Direct prompt injection & token smuggling
Mitigations & Countermeasures:
  • [Preventive] Dual-LLM Guardrail Verification & Prompt Hardening (Effort: Medium, Status: proposed)
    Deploy a dedicated, isolated guardrail classifier to inspect input/output tokens before passing to the execution LLM. Never embed secrets in system prompts.
Layer 2: Autonomous Agents

Goal Drift & Runaway Action Loop Hijacking in Telematics Unit

Target: Telematics Unit • Asset: Braking Signal • Status: DRAFT
Medium (12/25)

An attacker introduces conflicting sub-goals in an incoming task description, causing the autonomous agent to loop infinitely or prioritize attacker-supplied instructions over legitimate system constraints.

Attack Vector: Goal hijacking & autonomous loop subversion
Mitigations & Countermeasures:
  • [Preventive] Deterministic Step Counter & Goal Invariant Enforcement (Effort: Low, Status: proposed)
    Implement hard recursion limits (max 10 iterations) and enforce immutable core policy checks before each autonomous action step.
Layer 3: Environment & Tool Integrations

Arbitrary Command & SSRF Execution via Agent Tool Invocation

Target: Telematics Unit • Asset: Braking Signal • Status: DRAFT
Critical (20/25)

The agent possesses tools with high privilege (HTTP fetch, SQL query, or CLI execution). Indirect prompt injection causes the agent to invoke tools with attacker-controlled arguments.

Attack Vector: Tool privilege abuse & SSRF via tool parameters
Mitigations & Countermeasures:
  • [Preventive] Tool Argument Schema Validation & Sandboxed Execution (Effort: High, Status: proposed)
    Enforce strict Pydantic argument validation, block internal IP ranges (127.0.0.1, 169.254.0.0/16) in tool handlers, and execute tools in ephemeral gVisor/WASM sandboxes.
Layer 4: Storage, Context & Memory

Vector Store Poisoning & RAG Knowledge Corruption in Braking Signal

Target: Telematics Unit • Asset: Braking Signal • Status: DRAFT
Medium (12/25)

Attacker uploads a poisoned document into the RAG ingestion pipeline containing high-similarity adversarial text designed to dominate search results and inject malicious instructions into downstream prompts.

Attack Vector: RAG vector database poisoning & semantic hijacking
Mitigations & Countermeasures:
  • [Preventive] Ingestion Sanitization & Tenant-Isolated Vector Namespaces (Effort: Medium, Status: proposed)
    Sanitize and strip hidden text/metadata before chunking. Isolate vector indexes per tenant with strict cryptographic access control.
Layer 6: Orchestration & Multi-Agent Swarms

Subversion of Multi-Agent Consensus & Rogue Worker Impersonation

Target: Telematics Unit • Asset: Braking Signal • Status: DRAFT
Medium (10/25)

In a multi-agent swarm architecture, lack of mutual cryptographic verification allows a compromised worker agent to forge consensus votes or spoof messages from the coordinator agent.

Attack Vector: Inter-agent message forgery & consensus manipulation
Mitigations & Countermeasures:
  • [Preventive] Cryptographically Signed Agent Messages & Quorum Verification (Effort: High, Status: proposed)
    Require each agent to sign messages with a dedicated key pair and enforce m-of-n quorum rules for high-consequence swarm actions.
Layer 7: User Interface & Human-in-the-Loop

Confirmation Fatigue & Clickjacking on High-Risk Action Approvals

Target: Telematics Unit • Asset: Braking Signal • Status: DRAFT
High (16/25)

The agent bombards the human supervisor with routine approval requests, inducing confirmation fatigue, and subtly changes parameters on a high-risk operation to secure unintended human approval.

Attack Vector: Approval coercion & human-in-the-loop bypass
Mitigations & Countermeasures:
  • [Preventive] Tiered Action Friction & Re-Authentication for Critical Tasks (Effort: Low, Status: proposed)
    Require explicit confirmation with re-authentication (passkey/password) and clear differential visual styling for high-risk destructive actions.

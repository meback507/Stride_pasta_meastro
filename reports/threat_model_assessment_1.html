Spoofing

JWT Signature Verification Bypass in Telematics Unit

Target: Telematics Unit • Asset: Braking Signal • Status: APPROVED
Critical (20/25)

An attacker alters the algorithm header of the authentication token or exploits weak signing keys to impersonate legitimate security principals communicating with Telematics Unit.

Attack Vector: Cryptographic signature bypass / None algorithm acceptance
Mitigations & Countermeasures:
  • [Preventive] Strict Algorithm Whitelisting & Asymmetric Key Verification (Effort: Medium, Status: proposed)
    Reject tokens with 'none' or mismatched algorithms. Enforce RS256/ES256 verification using a cryptographically managed JWKS endpoint.
Tampering

In-Flight Parameter & Payload Tampering across Telematics Unit -> Braking Controller

Target: Braking Controller • Asset: Braking Signal • Status: DRAFT
Medium (8/25)

Lack of strict mutual TLS or cryptographic payload hashing enables attackers with internal network visibility to alter transaction instructions in transit.

Attack Vector: Man-in-the-Middle (MitM) packet manipulation
Mitigations & Countermeasures:
  • [Preventive] Enforce Strict Mutual TLS (mTLS) with Certificate Pinning (Effort: High, Status: proposed)
    Require bidirectional mTLS with cryptographic payload integrity verification on all inter-service communications.
Repudiation

Insufficient Audit Trail for Critical Administrative Actions in Telematics Unit

Target: Telematics Unit • Asset: Braking Signal • Status: DRAFT
Medium (12/25)

Administrative state modifications and privileged policy overrides in Telematics Unit are either unlogged or written to non-immutable local files without tamper protection.

Attack Vector: Log evasion and non-repudiation failure
Mitigations & Countermeasures:
  • [Detective] Centralized Write-Once-Read-Many (WORM) Audit Logging (Effort: Medium, Status: proposed)
    Stream audit logs in real-time over TLS to an immutable append-only SIEM with cryptographic log signing.
Information Disclosure

Unmasked Sensitive Data Leakage in Error Responses and Traces from Telematics Unit

Target: Telematics Unit • Asset: Braking Signal • Status: DRAFT
Medium (12/25)

Detailed stack traces, database schema fragments, and partial customer records in Telematics Unit are returned to client interfaces upon unhandled exceptions.

Attack Vector: Verbose error message disclosure & CWE-209
Mitigations & Countermeasures:
  • [Preventive] Global Exception Handler & Data Masking (Effort: Low, Status: proposed)
    Implement unified exception handlers that return generic RFC 7807 error responses while logging full sanitized stack traces internally.
Denial of Service

Unbounded Resource Exhaustion & Algorithmic DoS on Telematics Unit

Target: Telematics Unit • Asset: Braking Signal • Status: DRAFT
High (16/25)

Endpoints in Telematics Unit allow unrestricted payload sizes and nested JSON objects without rate limiting, causing CPU starvation and memory exhaustion.

Attack Vector: Resource exhaustion / Billion laughs / ReDoS
Mitigations & Countermeasures:
  • [Preventive] Strict Rate Limiting & Max Payload Size Enforcement (Effort: Low, Status: proposed)
    Apply token bucket rate limiting at Nginx/Gateway level and enforce max body size of 1MB.
Elevation of Privilege

Broken Object Level Authorization (BOLA/IDOR) in Braking Controller

Target: Braking Controller • Asset: Braking Signal • Status: DRAFT
Critical (20/25)

Users can access and modify records belonging to other tenants by manipulating numeric ID parameters in Braking Controller endpoints.

Attack Vector: Insecure Direct Object Reference (IDOR) / BOLA
Mitigations & Countermeasures:
  • [Preventive] Contextual Authorization Checks at Data Access Layer (Effort: Medium, Status: proposed)
    Validate that the authenticated session user explicitly owns or has permission on the requested resource ID at the repository layer.
